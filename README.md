Asset Zoo Builder

A Godot 4 editor plugin for batch-organizing, spacing out, and labeling 3D assets in a scene, useful for asset review, validation, and portfolio viewing.

Usage:

    In the FileSystem dock, select one or more .tscn files and right-click.

    Choose "Add to Asset Zoo" from the context menu.

    The plugin scans for scenes with the _zoo suffix. Select an existing *_zoo.tscn scene from the list, or create a new one.

Only .tscn files are placed; all other asset types are skipped.


Label Settings:

Labels can be resized and recolored from the top-level node (named after your scene) under the "Label Settings" heading.

Press X to toggle labels on and off, in the editor and live in-game. This hotkey can be changed in Label Settings.
